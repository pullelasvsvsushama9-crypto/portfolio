# Sushama Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Before publishing

1. Your supplied profile photo is already placed at `images/profile.jpg`.
2. Your supplied resume is already placed at `resume/Sushama_Resume.pdf`.
3. GitHub has been set to `https://github.com/pullelasvsvsushama9-crypto`.
4. Email has been set to `pullelasvsvsushama9@gmail.com`.
5. Your supplied KHub Task ChatBot repository is linked as the featured project.
6. Other project buttons point to your GitHub profile because their individual repository URLs were not supplied.
7. Replace the certification placeholder titles with the exact certificate names if desired.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

Create a repository, upload all files, then go to:
Repository → Settings → Pages → Deploy from branch → main → /(root) → Save.
